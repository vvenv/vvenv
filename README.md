### [5yong.com](https://5yong.com)

**[Alice 听写](https://alice.edao.plus)** — 英文单词听写 App。拍照或粘贴生成词表，自动朗读，可调语速与间隔，标错的词进错词本。内置中考 1600、高考 3500 和人教、外研、闽教版单元词表。Flutter，Android / iOS / Web。[源码](https://github.com/vvenv/alice)

**[汤姆猫跑酷](https://run.edao.plus)** — 原生 Android 3D 像素跑酷。三条跑道，穿过传送门进入六个世界。路上会刷出 88 件中国文物，每件带朝代与一句说明。免费，无广告，无内购。Kotlin + OpenGL ES 2.0。[源码](https://github.com/vvenv/tomrun)

**[一道+](https://edao.plus)** — 小学奥数讲解工具。面向 3–6 年级，每道题给分步图文讲解、多解法对照与结构化可视化场景，并与方法手册互链。不做题库堆砌。[源码](https://github.com/vvenv/onemath)

**[Rewindom](https://rewindom.com)** — 给编码 Agent 用的多租户 SaaS 底座。内核不含业务代码，业务以 TypeScript 模块挂载，按租户开关。人与 Agent 走同一条 `Spec → gen → check` 闭环。单进程 Docker Compose 部署。[文档](https://rewindom.com/docs) · [源码](https://github.com/vvenv/rewindom)

**[Vanilla WoW 私服](https://github.com/vvenv/wow)** — macOS Apple Silicon 上的 1.12.1。原版 Blizzard 客户端跑在 WoWSilicon 的 Wine 上，服务端是 Docker 里的 VMaNGOS，另配一个 SwiftUI 启动器。README 记录了完整搭建过程与踩坑。
