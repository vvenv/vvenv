### [wenfu.dev](https://wenfu.dev)

**[Alice 听写](https://alice.wenfu.dev)** — 英文单词听写 App。拍照或粘贴生成词表，自动朗读，可调语速与间隔，标错的词进错词本。内置中考 1600、高考 3500 和人教、外研、闽教版单元词表。Flutter，Android / iOS / Web。[源码](https://github.com/vvenv/alice)

**[汤姆猫跑酷](https://run.wenfu.dev)** — 原生 Android 3D 像素跑酷。三条跑道，穿过传送门进入六个世界。路上会刷出 88 件中国文物，每件带朝代与一句说明。免费，无广告，无内购。Kotlin + OpenGL ES 2.0。[源码](https://github.com/vvenv/tomrun)

**[一道+](https://edao.wenfu.dev)** — 小学奥数讲解工具。面向 3–6 年级，每道题给分步图文讲解、多解法对照与结构化可视化场景，并与方法手册互链。不做题库堆砌。[源码](https://github.com/vvenv/onemath)
